## Interpretation rules

All 205 extracted columns are included exactly once. Uncertain export character-length units are preserved rather than silently halved. SQL rowversion/timestamp is not wall-clock time; defaults do not imply automatic update triggers. Composite unique-key participation is not individual uniqueness. Unknown meanings remain explicit for retained historical tables, optional metadata and unsupported downstream processes. Complete definitions, actions, includes and filters are in 03; API-specific consumption is in 06. No production rows or personal values are included.
