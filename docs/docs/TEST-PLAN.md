# Pilot test plan

## Café Kiosk

- Employee card login
- External prepaid card login
- External postpaid/invoice card login
- Last-five-digit card-reader input
- Saved product layout
- Multiple quantities
- Successful employee purchase
- Successful external purchase
- Insufficient prepaid balance
- Credit-limit rejection
- Timeout and explicit cancel
- EN/SV/FI

## Reporting

- Overview totals match transaction totals
- Product totals match overview revenue
- Payroll total per employee
- External account totals
- Invoice and postpaid filters
- Payroll CSV
- External summary CSV
- External detail CSV
- Nordic characters and decimal commas
- Custom date range

## Lunch kiosk

- Employee card login
- Existing lunch order
- Salad order
- Guest lunch order
- My Orders view
- Language switching
- Activity resets timeout
- Timeout removes identity and returns to login
- Explicit logout removes identity
- External card receives the deliberate not-enabled message

## Feedback to collect

- Was card scanning obvious?
- Were product/meal choices understandable?
- Did users notice the confirmation?
- Was 60 seconds sufficient?
- What information did kitchen staff miss?
- What reporting fields did FINA ask for?
- Who should be allowed to change products, images, layouts and reports?
