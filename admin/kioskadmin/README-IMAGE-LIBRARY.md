# Image library

Deploy these complete files to `admin/kioskadmin/`:

- `image-library.html` (new)
- `image-library.js` (new)
- `cafe-kiosk-admin.css` (complete replacement)

Open `/admin/kioskadmin/image-library.html`. The package does not change the admin landing page because that file was not included.

Features: search, used/unused counts, unused-only filter, full preview, metadata, usage count and safe deletion of unused images.
