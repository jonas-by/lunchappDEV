# Café Kiosk product image display patch

Deploy the complete replacement file:

- `bulla/order.js`

No HTML or CSS change is required. The existing kiosk markup and CSS already support square product images with `object-fit: cover`.

The change loads the default layout and the current product library in parallel, then merges the newest product data into the layout items. This ensures the kiosk receives the managed `imageUrl` returned by the product API while preserving layout columns, rows and visibility settings.

Fallback order remains:

1. Product image
2. Configured icon
3. Package emoji
